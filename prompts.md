# 🤖 Engenharia de Prompts e Cicatrizes

Este documento apresenta os prompts utilizados durante o desenvolvimento do Caderno Temático AWS utilizando o NotebookLM.

O objetivo foi utilizar a Inteligência Artificial como ferramenta de aprendizagem, realizando testes, ajustes e melhorias nos comandos para obter respostas mais completas e relevantes.

---

# Prompt 1 — Introdução à Computação em Nuvem

## Pergunta inicial:

"Explique o conceito de computação em nuvem AWS para uma pessoa que está começando na área de tecnologia."

## Resultado obtido:

A Inteligência Artificial apresentou uma explicação introdutória sobre Cloud Computing, destacando:

- Uso de recursos pela internet.
- Escalabilidade.
- Redução de custos.
- Flexibilidade.

## Cicatriz / Melhoria:

A primeira resposta apresentou conceitos muito gerais.

Foi necessário adicionar mais contexto:

"Explique utilizando exemplos reais de empresas e serviços AWS."

## Resultado após ajuste:

A resposta ficou mais prática, relacionando conceitos com serviços como EC2, S3 e RDS.

---

# Prompt 2 — Comparação de Serviços AWS

## Pergunta inicial:

"Compare Amazon EC2, Amazon S3 e Amazon RDS."

## Resultado obtido:

A IA explicou que cada serviço possui uma finalidade diferente:

- EC2 → Computação.
- S3 → Armazenamento de objetos.
- RDS → Banco de dados.

## Cicatriz / Melhoria:

A resposta inicial estava muito técnica.

Foi solicitado:

"Explique a diferença utilizando exemplos de aplicações do dia a dia."

## Resultado após ajuste:

A comparação ficou mais fácil de compreender e aplicar em cenários reais.

# Prompt 3 — Preparação para Entrevista Cloud

## Pergunta:

"Crie perguntas de entrevista para uma vaga de Cloud Computing nível Júnior."

## Resultado obtido:

Foram geradas perguntas sobre:

- AWS EC2.
- S3.
- IAM.
- Segurança.
- Redes.
- Modelo de responsabilidade compartilhada.

## Aprendizado:

O prompt ajudou a identificar os assuntos mais importantes para preparação profissional.

# Prompt 4 — Criação de Resumo Técnico

## Pergunta:

"Resuma este conteúdo técnico mantendo os principais conceitos e exemplos práticos."

## Resultado:

A IA ajudou a organizar informações extensas em um formato de revisão mais simples.

---

# Principais aprendizados sobre Engenharia de Prompts

Durante o projeto foi possível perceber que bons resultados dependem de:

- Contextualizar o objetivo.
- Definir o nível de conhecimento esperado.
- Solicitar exemplos práticos.
- Refinar perguntas quando necessário.
- Avaliar criticamente as respostas geradas pela IA.

A Inteligência Artificial foi utilizada como ferramenta de apoio, mantendo a análise humana como parte essencial do processo.
