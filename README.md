#  Tema Escolhido

## Fundamentos de Computação em Nuvem AWS

A computação em nuvem é um modelo que permite acessar recursos de tecnologia pela internet, como servidores, armazenamento, bancos de dados e aplicações, sem a necessidade de manter uma infraestrutura física própria.

A AWS (Amazon Web Services) é uma das maiores plataformas de computação em nuvem do mundo, oferecendo diversos serviços para empresas de diferentes tamanhos.

---

#  Serviços AWS Estudados

## Amazon EC2

O Amazon Elastic Compute Cloud (EC2) fornece capacidade computacional escalável na nuvem.

Principais utilizações:

- Hospedagem de aplicações.
- Criação de servidores virtuais.
- Execução de sistemas e serviços.

---

## Amazon S3

O Amazon Simple Storage Service (S3) é um serviço de armazenamento de objetos.

Utilizado para:

- Armazenamento de arquivos.
- Backup.
- Data Lakes.
- Hospedagem de conteúdo estático.

---

## Amazon RDS

O Amazon Relational Database Service (RDS) permite criar bancos de dados relacionais gerenciados pela AWS.

Exemplos:

- MySQL
- PostgreSQL
- Oracle
