# 📘 Glossário AWS - Fundamentos de Computação em Nuvem

Este glossário reúne os principais conceitos estudados durante o desenvolvimento do Caderno Temático AWS utilizando o NotebookLM.

---

# ☁️ Computação em Nuvem (Cloud Computing)

Modelo de entrega de recursos de tecnologia através da internet, permitindo utilizar servidores, armazenamento, bancos de dados e outros serviços sem necessidade de manter uma infraestrutura física própria.

---

# AWS (Amazon Web Services)

Plataforma de computação em nuvem da Amazon que oferece diversos serviços para criação, implantação e gerenciamento de aplicações.

---

# Região AWS (Region)

Localização geográfica onde a AWS possui infraestrutura de data centers.

Exemplo:

- Região São Paulo (sa-east-1)

---

# Availability Zone (AZ)

Um ou mais data centers isolados dentro de uma Região AWS.

São utilizadas para aumentar disponibilidade e confiabilidade das aplicações.

---

# Amazon EC2

Serviço de computação da AWS que permite criar máquinas virtuais na nuvem.

Principais utilizações:

- Hospedar aplicações.
- Executar servidores.
- Processar dados.

---

# Instância EC2

É uma máquina virtual criada dentro do Amazon EC2.

Ela possui:

- Sistema operacional.
- Processamento.
- Memória.
- Armazenamento.

---

# Amazon S3

Serviço de armazenamento de objetos da AWS.

Utilizado para:

- Arquivos.
- Backups.
- Imagens.
- Dados de aplicações.

---

# Bucket

É um recipiente utilizado pelo Amazon S3 para armazenar objetos.

Exemplo:

Um bucket pode armazenar documentos, imagens e arquivos de uma aplicação.

---

# Objeto

Qualquer arquivo armazenado dentro de um bucket S3.

Pode ser:

- Documento.
- Imagem.
- Vídeo.
- Arquivo de dados.

---

# Amazon RDS

Serviço de banco de dados relacional gerenciado pela AWS.

Permite utilizar bancos como:

- MySQL.
- PostgreSQL.
- Oracle.

---

# IAM (Identity and Access Management)

Serviço responsável pelo gerenciamento de usuários, permissões e controle de acesso aos recursos AWS.

---

# Política IAM (Policy)

Documento que define quais ações um usuário ou serviço pode realizar dentro da AWS.

---

# Role (Função IAM)

Permissão temporária concedida para usuários ou serviços acessarem recursos AWS.

---

# Snapshot

Cópia de segurança de um volume ou recurso que pode ser utilizada para recuperação de dados.

---

# Escalabilidade

Capacidade de aumentar ou reduzir recursos conforme a demanda da aplicação.

---

# Elasticidade

Capacidade de ajustar automaticamente recursos conforme necessidade.

---

# Alta Disponibilidade

Característica de sistemas projetados para permanecerem funcionando mesmo quando ocorrem falhas.

---

# Modelo de Responsabilidade Compartilhada

Modelo onde a AWS é responsável pela segurança da infraestrutura e o cliente é responsável pela segurança dos dados e configurações dos seus recursos.

---
